### Influencer Products

Influencer Products is a static webpage built using HTML and CSS.
It showcases products promoted by influencers with a banner, product section, and footer.

🌐 Live Website: https://rakib120822.github.io/influencer-gear/

### 📝 Project Overview

A clean and minimal static homepage highlighting influencer products.

Main Sections:

Banner Section – visually engaging hero banner

Products Section – showcases featured merchandise

Footer Section – contains links and additional information

### 🛠️ Technologies Used

HTML5

CSS3

    # images and other media files

### 🚀 How to Use

Clone the repository:

git clone https://github.com/rakib120822/influencer-gear.git


Navigate to the project folder:

cd influencer-gear


Open index.html in a browser to view the page.
